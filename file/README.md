

## Tools
* S3UploaderV3.py: GUI Tools to make upload to the S3 with ease, especially for the large file with the multipart upload supported. You can select size to each chuck (min 5MB) and concurrency upload chuck with copy upload or move mode (delete local), also have automatic retries and failed to upload status file (not delete the local if failed). Multi Files and Folder supported (recursively move child folder)
* xmconn.py: GUI Tools (In Development) to extract the live video, record video and some metadata of the XMEye DVR (formally known as H264, OEM DVR)

* DVRPREPOSTPROCESS.py: CLI Automatic tools to Process the XMEyes DVR Video pushed via FTP Uploads into the standard container with the compressed video resolution.
